# Proyecto Odontología · Plataforma de gestión dental

Contexto del proyecto para cualquier persona (o sesión de Claude) que trabaje en este repo.
Lo mantenemos entre todos: si se toma una decisión nueva con una clínica, se anota acá.

## Quiénes somos

- **sobrinos** (agencia): Agustín y Gabi. Los dos trabajan sobre este repo.
- **Vertical:** Clínicas Odontológicas y Policonsultorios Dentales de Mar del Plata (ej. CEO Red, Sol Odontología, Dental Axis, COA) + integración de flujo con centros de imágenes (**Dental Scan**).

## Estado

Prototipo navegable 100% funcional con **datos ficticios** (Pacientes odontológicos, Especialistas por sillón, Dirección y Secretaría).
Todo vive en memoria y en `localStorage` del navegador (con prefijo `odonto-` para no pisar `ctp-plataforma`).

- Publicado en Vercel desde `main` (cada push a `main` se publica solo).
- Todo el prototipo está en **un solo archivo**, `index.html`: estilos, datos de muestra y lógica.
- Sin build ni dependencias externas. Se abre directo en el navegador.
